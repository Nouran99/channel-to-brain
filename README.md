# Channel to Brain

Work in progress. This repository is not ready to install or use yet.

Channel to Brain is a method for turning a creator's public YouTube channel into a source-attributed knowledge package for an AI assistant, with honest coverage counts and a rule that the agent asks before consequential steps.

The package is being extended to cover more than one AI client, and each client needs its own format checked against its official documentation first. Until that is done and tested, nothing here should be treated as complete, installed or verified in any client.

No license has been chosen yet.
